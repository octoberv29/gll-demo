# GLL — демо кабинета

Демо 4PL-кабинета для новых клиентов: https://octoberv29.github.io/gll-demo/

Сделано в Claude Design, потом распаковано в обычные файлы и переведено на дизайн и язык рабочего кабинета PepsiCo (`4pl-backend/frontend`): тёмная панель слева, «Рейсы» с полосой итогов, карточка рейса с простоем по ТТН и претензией перевозчика, «Документы» с фильтрами по типу и этапу цепочки.

- `index.html` — всё демо: стили, разметка экранов и в конце `<script type="text/x-dc">` с данными (`DATA`, `TRIPS`) и логикой.
- `dc-runtime.js` — шаблонизатор Claude Design (`sc-if`, `sc-for`, `{{ }}`). Сгенерирован, не править.
- `vendor/` — React 18, `fonts/` — Manrope, JetBrains Mono, Material Symbols. Всё локально, интернет не нужен.

Открыть локально: `python3 -m http.server 3310` в этой папке и http://localhost:3310 (через `file://` не работает — рантайм грузит файлы запросами).

Внутри таблицы (`<table>`, `<tbody>`) `sc-for` не работает: браузер выносит неизвестные теги из таблицы. Таблицы здесь — сетка из `div` с `role="table"`.
